# 应天龙 EchoSkyDragon · 造字编辑器

> 造 OC 字或改字体用。

单文件、离线可用的造字／改字体工具：先建文字体系，再逐字元画字形，最后导出可安装字体。

打开 `index.html` 即用，无需构建、无需联网、无外部依赖。

## 功能

- **文字体系**：替换文字、表音文字、表意文字、混合文字；书写方向、视觉风格、排版（含竖排上→下 / 下→上）。
- **字元绘制**：写画模式与像素模式；画笔／橡皮／拉线均可被磁吸；九宫米字格、四线三格、辅助格与可调步长；参考图（透明度、双指移动缩放、删除）。
- **字元管理**：文字系统列表、批量建字（A-Z / 基础音节模板）、字元 XML 导入导出、文字体系 JSON 导入导出、映射键位冲突检测。
- **字形微调**：笔画大小数值实时显示与数字输入、字距微调、字母专用左右边距自动缩小、读音与释义分离。
- **导出**：TTF（含无平滑选项，预览与导出一致）、展示页长图、展示页 HTML（只读玩具版）。
- **展示页**：体系信息、字元信息与样貌、预览文，自动截取内容区。

细节规格见 [SPEC.md](SPEC.md)。
